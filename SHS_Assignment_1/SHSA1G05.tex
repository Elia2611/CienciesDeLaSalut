We need to perform a variable selection because adding variables can degrade the classification when the number of subjects is small compared to the numer of variables. As mentioned in the article, it is good practice that the number of subjects are at least 10 times the number of variables.
In our case, the ratio is $342 / 44 < 10$, so a reduction of the number of variables is needed.

As in the original analysis, we use the backward search with CritCF criterion. It starts with all the variables and, at each step, removes the variable that when excluded gives the highest CritCF. This criterion allows to rank partitions with different numbers of clusters and different numbers of variables.
Finally, we define \texttt{k = 2:5} where the maximum value was fixed a priori, the same way as the article. Since the backward seach is repeated for each $k$ in each imputed data set, limiting the number of clusters reduces the computational cost and also keeps the resulting groups interpretable.

To find the number of clusters, we applied the backward search with the CritCF criterion to each of the 100 imputed data sets. Figure~\ref{fig:fig_critcf} shows that even the worst value for $k = 2$ is above the best value for $k = 3$, so $k = 2$ was the optimal number of clusters in all the imputed data sets. Therefore, there is practically no uncertainty in the choice of $k$.
After the assignation, the clusters contain 184 and 158 subjects.

To prevent a potential problem caused by the automatic labeling of the clusters, the clusters were relabeled taking the first data set as a reference and evaluating them with Cohen's kappa, same as the article. The agreement after relabeling is good, with a median Cohen's kappa of 0.97.

For $k = 2$, 15 of 33 variables candidates were selected in at least one data set(Figure~\ref{fig:fig_varsel} and \ref{fig:fig_barplot}).
The final number of selected variables is 13, with 11 of those that are in all the imputed data sets.
There is a clear drop in frequency right after the last selected variable (from 90\% to 37\%). Also, we see that the selected variables would be the same if we kept those appearing in more than 50\% of the data sets. Therefore, the variable selection is very robust to the missing data.

Each subject was assigned to the cluster to which they were allocated most often across the imputed data sets.  In table ~\ref{tab:alloc} we can see how this frequency is distributed in  $k = 2$ and  $k = 3$.  For $k = 2$, the median probability is 1.00 and 1.00 in both clusters, so most subjects are always assigned to the same cluster.  For $k = 3$, the assignment is also very stable, and this is probably because the selected variables have few missing data, so the imputed data sets are very similar. Given this, we see that a stable assignment does not necessarily mean that the clusters are adequate, we have already seen that the choice of $k = 2$ is supported by the CritCF criterion.
Table~\ref{tab:desc} shows that cluster 2 groups the subjects with more severe disease with worse lung function, more air trapping, lower arterial oxygen and worse scores in the questionnaires. We also see that results with raw and imputed data are very similar.
